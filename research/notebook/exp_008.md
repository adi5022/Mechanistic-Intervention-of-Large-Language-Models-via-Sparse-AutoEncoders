# Experiment: Shared Feature Aggregation (max() vs sum())

**Experiment ID**: EXP-008  
**Date**: 2026-07-25  
**Status**: Completed  

---

## 1. Context & Objective
### Question
Does the Weighted Multi-Competitor Reduction underestimate the importance of shared SAE features because it keeps only the maximum competitor contribution when multiple competitors map to the same feature?

### Background
Under the previous implementation, if multiple competitors shared a feature (e.g. Feature 313), only the maximum computed strength was applied:
```
Feature 313 Mute Strength = max(0.284, 0.166, 0.041) = 0.284
```
This experiment tests whether additive accumulation (`sum()`) with post-aggregation ceiling clamping (`min(..., max_strength)`) improves the performance of the Weighted Reduction intervention.

---

## 2. Hypothesis & Setup
### Hypothesis
* **H10**: The current Weighted Multi-Competitor Reduction underestimates the importance of shared SAE features. Replacing maximum aggregation with additive accumulation (clamped at `max_strength` ceiling) will allow shared competitor directions to be muted more strongly, resolving the rank suppression of the target.

### Experimental Setup
* **Model**: GPT-2-small (Layer 8 Residual Stream)
* **SAE**: `gpt2-small-res-jb`
* **Test Case**: Cambridge MIT benchmark
* **Intervention**:
  - `max_strength = 0.7`, `top_n_candidates = 20`.
  - Replace `max()` aggregation with `sum()` aggregation:
    `feature_to_raw_strength[fid] += mute_strength`
  - Post-clamp strengths to `max_strength`:
    `feature_to_strength[fid] = min(raw_strength, max_strength)`

## 4. Discussion & Scientific Conclusions

* **Rejection of Hypothesis H10**: Experiment H10 rejects the hypothesis that the weak performance of Weighted Multi-Competitor Reduction is primarily caused by using maximum aggregation for shared SAE features.
* **Interpretation of Results**:
  - Increasing the intervention strength of the strongest identified shared feature (Feature 313) by approximately 73% (from `0.284` to `0.492`) produced only a marginal increase in the target probability (from `1.29%` to `1.39%`) and no rank improvement (remained at Rank 8).
  - This demonstrates that the strongest identified SAE feature alone is insufficient to substantially suppress these competitors.
  - One possible explanation is that these competitors derive support from multiple influential SAE features rather than a single dominant feature. This has not yet been experimentally verified, and motivates the next diagnostic phase (Experiment H11 / EXP-009).
