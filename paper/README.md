# Research paper (working folder)

- `main.tex`: IEEE conference template with the section skeleton and a note under each heading saying what belongs there. Written by the authors.
- `references.bib`: add an entry for every paper you cite, copied from the paper's own page (not from memory).
- `figures/`: put figures here; draw them from stored data (see `docs/report_v2/chapters/appendices.tex`, Appendix D).
- Compile: `tectonic -X compile main.tex` from this folder, or upload the folder to Overleaf.
