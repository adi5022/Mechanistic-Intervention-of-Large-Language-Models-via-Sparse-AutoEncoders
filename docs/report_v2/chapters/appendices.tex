\section*{Appendix C: Reproducing the Results}
\addcontentsline{toc}{section}{Appendix C: Reproducing the Results}

From the repository root, with \texttt{HF\_HUB\_OFFLINE=1} once the models are cached. The main line is on the branches \texttt{layer-\allowbreak intervention-\allowbreak benchmark}, \texttt{pool-\allowbreak refill-\allowbreak implementation} and \texttt{gradient-\allowbreak descent-\allowbreak editing}; the side study is on \texttt{cross-\allowbreak model-\allowbreak transfer}.

\begin{lstlisting}
streamlit run experiment_app.py
python run_batch.py data/candidate_source_batch_spec.json
python tools/build_counterfact_set.py
python tools/split_counterfact_set.py
python tools/build_strength_cache.py
python tools/measure_headroom.py
python tools/train_strength_models.py
python tools/compare_sweep_vs_gradient.py --n-per-band 0
python tools/control_random_targets.py
python tools/transfer/00_setup_check.py   (then 01 to 27)
python tools/make_report_v3_history_figures.py
\end{lstlisting}

In order: the application; the candidate-source study; the CounterFact hard set and split; the per-prompt cache and the headroom measurement; the strength networks; the 271, 161 and 94 of 300 comparison; the random-word control; the side study; and the early-stage figures.

Journal entries 31 to 37 give each side-study tool with its run time, and \texttt{docs/\allowbreak cross\_\allowbreak model\_\allowbreak transfer/\allowbreak PLAN.md} holds all pass bars and readings.
