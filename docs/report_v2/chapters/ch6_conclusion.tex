\chapter{Conclusion and Future Work}\label{ch:conclusion}

\section{Conclusion}

This report started from a transient edit of GPT-2 Small through the features of a sparse autoencoder, which brought the true answer to rank 1 on 271 of 300 held-out prompts, and asked whether the change such an edit makes can be carried into another model at inference time. The answer has four parts.
\begin{enumerate}
  \item \textbf{A channel exists.} A linear map fitted on ordinary text keeps GPT-2 Medium working and carries a known meaning change far above controls (55\% and 33\% against under 0.5\%).
  \item \textbf{Export carries a push, not a fact.} An edit tuned only in Small lifts the target's median rank in Medium from 142 to 14 specifically and without harming neighbours, but reaches rank 1 on only 8\% of records. Seven attempts to improve it (other layers, a neural map, a map trained on edits, longer training, a rank-1 loss, more and more varied training edits) stop at about 20\% at best; tuning the edit against Medium's output for each sentence reaches 95\%, so the channel can carry a rank-1 edit and the limit is the edit's compatibility with the receiver. Reworded prompts move equally for a random target word, so what crosses is a push toward the word.
  \item \textbf{Import works as a small mix.} Replacing Small's state by Medium's rescues one in three of the facts Small gets wrong but lowers its accuracy; a half-and-half mix raises accuracy on held-out facts from 8.5\% to 9.5\% while keeping 98\% of the facts both models knew.
  \item \textbf{The SAE helps but is not required.} Small's SAE directions raise the steering success of per-sentence tuning from 81\% to 95\% over random directions with the same activation pattern.
\end{enumerate}
Every pass bar was fixed before its run, every failure is recorded with its evidence, and two earlier statements were corrected when a fairer baseline was applied.

\section{Future Work}

\begin{itemize}
  \item \textbf{Import.} Rerun the controls of the replacement test for the mix, test it on reworded prompts and other relations, and train the Import map so that Small's answers become right (the analogue of the map trained on edits).
  \item \textbf{Export.} Learn the per-sentence solution instead of tuning it (an ``amortised'' version of the ceiling), or a map that depends on the sentence; a regularised or non-linear map trained on many edits was designed but not completed.
  \item \textbf{Generality.} Other relations and model pairs (for example Gemma 3 270M and 1B, which have SAEs on both sides), the additive edit, generated text, and larger donors.
  \item \textbf{Comparison.} Head-to-head comparison with ROME, MEMIT and in-context editing, and a check of the related-work claims against the full text of the stitching papers.
\end{itemize}
