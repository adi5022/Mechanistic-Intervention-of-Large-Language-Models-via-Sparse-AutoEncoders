\chapter{Implementation}\label{ch:implementation}

\section{Software, Hardware and Code Organisation}

The system is written in Python with PyTorch 2.6 \cite{r22}, TransformerLens 3.5.1 \cite{r13} and SAELens 6.45.3 \cite{r14}, and runs on a single laptop GPU (NVIDIA RTX 4050, 6 GB) under Windows 11. The first part of the project, the SAE edit and its Streamlit application with seven tabs, is unchanged and is described in the first report. The transfer study adds only new files: the library \texttt{src/transfer/} (translators, edits relayed through a map, the batched trainer, judges, Import) and the numbered command-line tools \texttt{00} to \texttt{27} in \texttt{tools/transfer/}, one per experimental step. Older functions are imported and never edited, so earlier results cannot change.

\section{Reproducibility}

Every tool prints its pass rule, saves its raw terminal output as a log, and writes a result file with per-run details (epoch curves, doses, seeds) and not only the final numbers. Result files and logs of every experiment are copied into a data pack under version control; all figures in this report are drawn from that pack alone by a script that runs no model. Larger local artefacts (trained maps, per-sentence results, caches; 2.6 GB) are not in git; they are packed with a manifest of file sizes and checksums, and the code commit they were made with, so that a restored copy can be verified. Pass bars were committed to the plan file before the corresponding tool was run, so the order of events can be checked in the repository history.

\section{Engineering Notes}

\textbf{Batched training.} The trainer of the map pads texts to one length and sends them through the remaining layers of medium together; because the model is causal, padding does not change the result (the per-text loss differs from the one-at-a-time code by $3\times10^{-6}$, the gradient cosine is 1.000000), and training became about 14 times faster. \textbf{GPU memory.} The largest training set (7,550 texts padded to 57 tokens, 3.8 GB) nearly filled the 6 GB card; runs then slowed five- to ten-fold without any error (the varied-edits run took 6.2 hours instead of the one hour estimated). Training tensors are now kept off the GPU and time estimates are taken from the largest measured set. \textbf{A correction found by reading.} The ``rewordings'' figure of the random-word control was first compared with the real target's unchanged level instead of its own; this was found, recomputed, and the earlier claim withdrawn (Section~\ref{sec:push}).
