## 1. Layman's Explanation (The Multi-Feature Steering Sweep)

Building on the findings of Entry 7, which showed that semantic competitors have highly distributed representations across multiple SAE features, we tested a new steering method: **Weighted Multi-Feature Competitor Reduction**.

Instead of muting only the single top driving feature for each competitor, we selected the **Top-K** features per competitor, distributed each competitor's weight across those $K$ features using three experimental weighting strategies (Equal, Delta-Normalized, Softmax), aggregated the muted strengths, and measured the final impact on the target completion.

We found that muting multiple features (specifically $K=3$) significantly outperforms muting a single feature, successfully recovering the target token `" Cambridge"` to **Rank 6** (from clean Rank 8 and $K=1$ Rank 8).

## 4. Scientific Conclusions

1. **Top-K Multi-Feature Steering Improves Performance**:
   - Muting $K=3$ features per competitor results in the best target rank recovery (**Rank 6** compared to Rank 8 in clean baseline and $K=1$). This shows that distributing muting strength across multiple causal channels is more effective than focusing entirely on a single top feature per competitor.

2. **Equal and Softmax Strategies Outperform Delta-Normalized**:
   - At $K=3$, distributing weights evenly (`equal`) or using a temperature-scaled `softmax` outperforms `delta_normalized`. Delta-normalization tends to concentrate too much strength on the first feature, leaving the other distributed features insufficiently suppressed.

3. **Dilution Decay at Higher $K$**:
   - At $K=5$, performance degrades back to Rank 7 / 1.34%. This indicates that including too many weak features dilutes the muting strength of the core causal features.
