## 1. Executive Summary

Before designing a multi-layer intervention benchmark, we conducted a systematic audit of the available pretrained Sparse Autoencoder (SAE) dictionaries in `SAELens` for `gpt2-small-res-jb`. 

The audit verified complete coverage across all 12 transformer blocks ($0 \dots 11$) for residual stream pre-activations (`hook_resid_pre`). We also mapped out the external release structure for other hook locations (`hook_resid_post`, `hook_mlp_out`, `hook_attn_out`).

---

## 2. Experimental / Audit Methodology

We developed a standalone verification utility ([investigate_gpt2_saes.py](file:///d:/Work/PROJECTS/FeatureScalpel/investigate_gpt2_saes.py)) that:
1. Queries the `SAELens` pretrained directory registry (`sae_lens.loading.pretrained_saes_directory`).
2. Enumerates every registered SAE ID under `gpt2-small-res-jb`.
3. Evaluates structural availability for every block ($0 \dots 11$) across four standard transformer hook locations (`hook_resid_pre`, `hook_resid_post`, `hook_mlp_out`, `hook_attn_out`).

## 4. Architectural Findings & Key Takeaways

1. **Complete Layer Coverage**:
   - `gpt2-small-res-jb` has 100% complete coverage for `blocks.{layer}.hook_resid_pre` across all 12 layers of GPT-2 Small ($0 \dots 11$).
2. **Release Specificity**:
   - The `gpt2-small-res-jb` release contains exclusively residual stream pre-activation dictionaries.
3. **Cross-Release Hook Mapping**:
   - For interventions targeting other hook locations in GPT-2 Small, distinct SAELens releases are available:
     - `gpt2-small-resid-post-jb` -> `blocks.{layer}.hook_resid_post`
     - `gpt2-small-mlp-out-jb` -> `blocks.{layer}.hook_mlp_out`
     - `gpt2-small-attn-out-jb` -> `blocks.{layer}.hook_attn_out`
     - `gpt2-small-hook-z-jb` -> `blocks.{layer}.hook_z`
