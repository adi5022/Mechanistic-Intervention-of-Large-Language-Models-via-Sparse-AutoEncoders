## 1. Why
Entry 32 ended with the export failing its pre-set bar: the edit tuned in GPT-2 small and carried to GPT-2 medium made the target medium's top answer on only 5 to 8% of records, although its rank improved a lot. Four candidate reasons were listed (a training target that favours common structure; an edit tuned for small's later layers; a translator that never saw edited states; a single injection layer). This entry tests the last one directly (D5), tests whether the channel can carry a rank-1 edit at all (D6), and prepares the test of the first three (D7). It also records what the author's questions made explicit about the method (section 2).

## 2. What exactly was done (plain, as clarified with the author)
- **The edit is the multiplier edit, not the additive one.** In GPT-2 small the project's gradient-descent tool tunes one multiplier per candidate SAE feature (200 features at layer 8, `gpt2-small-res-jb`) until small answers with the counterfactual target (for example " English" instead of " French" for "The mother tongue of Danielle Darrieux is"). It reaches rank 1 in small on 116 of 200 benchmark records (58%); the main numbers use the 88 test records where it did. The additive edit (Entry 30; it reaches rank 1 on every prompt but also on 20 of 20 random words, and writes at 126 to 192% of the residual norm) was **not** used and its transfer is **untested** (Entry 31 predicted it would transfer worse, because it sits at the last position where the translator is weakest; that is a prediction).
- **What is injected.** The change the edit makes to small's layer-8 state at every position (edited minus unedited), translated by the linear map (never the whole state), times a dose, added to medium's residual stream at layer 12 and/or 16 while it reads the same sentence. No weight is changed in either model.
- **No SAE on medium.** The recipe (feature ids and multipliers) comes from small's SAE. What was tuned on medium's side: the translator was fitted on medium's activations over ordinary text (wikitext, no edits), and two scalars (dose and injection layer) were chosen from medium's outputs on 50 separate dev records; an outcome-free norm-matched dose agreed. The 150 test records were never used for any choice.
- **The rank numbers.** On the 88 test records, medium's median rank of the target is 142 before anything. (165 was the median on the earlier 30-record pilot.) After the injection the median is 14 (layer 16) or 11 (layers 12 and 16). It is a median over records, not true for every record; the target becomes top-1 on only 5 to 8%.

## 3. Method (new files only; older code untouched)
| Step | What | Files |
|---|---|---|
| D5 | The translated edit added at one layer of medium (4, 8, 12, 16, 20) or at several at once (12+16, 8+12+16, 12+16+20, 8+12+16+20, all five), the dose split over the layers (same total push) or the full dose at each (a bigger push, exploratory). Dose chosen per configuration on the dev records; norm-matched dose as a cross-check; controls: random vector, another record's edit | `tools/transfer/10_multilayer_export.py`, `src/transfer/multilayer.py`; table into the pack by `tools/transfer/13_pack_d5_table.py` |
| D6 | The same 200 small features and the original loss and settings, but the loss (rank hinge, KL once the target leads, size penalty) is measured on MEDIUM's last-position logits after small's change is translated (linear map small 8 to medium 16), scaled by the fixed dose 2.0 and added at medium's layer 16. Gradient descent changes only the multipliers. Controls: the same tuning toward a rank-matched random word, another record's tuned recipe, the original small-tuned edit | `tools/transfer/11_b_aware_edit.py`, `src/transfer/b_aware_edit.py` |
| D7 (design, not run in this entry) | A linear map small 8 to medium 16, started at the ridge solution, trained so that medium's answers move the way small's answers move under an edit: goal = log-softmax(medium's clean logits + (small's edited logits minus small's clean logits)), loss = KL(goal, medium's logits after injection). Up to 800 training records requested, disjoint from every dev, test, pilot and ROME-dev record and from the target words and subjects of dev and test records (the held-out rule dropped 829 of 1,450 candidates; 621 were edited in small and 289 of those edits reached rank 1, giving 1,445 training texts); edit tuned in small as in D2; relay on the tuned prompt, 2 rewordings, 2 neighbours. Epoch chosen on the 50 dev records, then the dose | `tools/transfer/12_output_matching.py`, `src/transfer/output_matching.py` |

All gates were written in `PLAN.md` before the corresponding run (D6's and D7's neighbour line is discussed in section 5).

## 4. Results
### 4.1 D5: several layers at once (88 test records whose edit reached rank 1 in small; `packs/.../d5_multilayer.json`, `d5_configs.json`; Figure 1)
Medium unchanged: target top-1 0%, median rank 142; rewordings (new beats true) 36%; neighbours (true still beats new) 67%.

| Configuration (dose chosen on dev) | Top-1 | Median rank |
|---|---|---|
| layer 4 / 8 / 12 / 16 / 20 alone | 0% / 5% / 5% / **8%** / 1% | 73 / 27 / 23 / **14** / 25 |
| 12+16, dose split | 7% | **11** |
| 8+12+16, 12+16+20, 8+12+16+20, all five (split) | 14% / 7% / 7% / 7% | 12 / 14 / 16 / 17 |
| the same sets with the full dose at each layer (exploratory) | 7% / 14% / 2% / 7% / 11% (12+16, 8+12+16, 12+16+20, 8+12+16+20, all five) | 11 / 12 / 22 / 16 / 21 |
| controls (random vector, another record's edit), any configuration | 0 to 2% | |

Gate 4 (fixed before the run): best single layer on dev (layer 16, test 8%) against best split set on dev (12+16, test 7%): (a) difference -1 point against +10 needed; (b) paired p = 0.016 against 0.01; (c) 7% against 15%: **FAIL**. Stage 2: rewordings 52% (layer 16) and 55% (12+16); neighbours 63% and 62%; the edit inside small itself 67% and 54%. The proposed rerun bar (top-1 50%, rewordings lift 80% of the edit's own, neighbours fall at most 5 points; proposed by Claude, not gated) on layer 16: 8%, 0.62 and 4 points: **not met**.
Reading: layers 8, 12 and 16 behave alike, layer 4 is weak and layer 20 poor, and splitting over several layers does not help, so the injection layer is not what limits the export. The median rank of the set is a little better (14 to 11), a faint hint only. The 14% of the set 8+12+16 was not the set chosen on dev and 88 records means one record is about one point; it is not a result.

### 4.2 D6: the ceiling test (88 primary test records; 150 in brackets; `packs/.../d6_b_aware.json`; Figure 2)
| Tuned prompt, medium layer 16, dose 2.0 | Top-1 | Median rank |
|---|---|---|
| medium unchanged | 0% (0%) | 142 (256) |
| original edit (tuned in small, as in D3) | 8% (5%) | 14 (27) |
| **edit tuned through the translator against medium** | **95% (84%)** | **1 (1)** |
| the same tuning toward a rank-matched random word (judged on that word, which starts at median rank 174) | 83% (67%) | 1 (1) |
| another record's tuned recipe | 0% (0%) | 154 (248) |
Rank 1 was reached at training time on 95% and the hook path agrees on every record (0 mismatches). The injected change is a median 26% of medium's residual norm at the last position (the original edit is 29% in small).

| Relay on other prompts (88 records) | Rewordings: new beats true | Neighbours: true still beats new | Unrelated: KL / top-1 flips |
|---|---|---|---|
| medium unchanged | 36% | 67% | 0 / 0% |
| original edit (D3) | 52% | 63% | 0.032 / 11% |
| **tuned through the translator** | **60%** | **59%** | 0.024 / 11% |
| tuned toward a random word | 42% | 64% | 0.026 / 13% |
| another record's tuned recipe | 34% | 68% | 0.026 / 14% |
| small, with the edit itself (reference; small unchanged 40% and 63%) | 67% | 54% | 0.014 / 14% |

Gate 5 (fixed before the run): (a) top-1 95% against 50%: ok; (b) rewordings lift 24 points = 0.91 of the 27 the edit gives in small, against 0.8: ok; (c) neighbours fall 8 points against 5 allowed: **no, so the gate FAILS**. The reading fixed in advance for this pattern was "a push on the tuned prompt, not a generalising change". Two notes written after seeing the result (they do not change the verdict): the edit itself, applied in small, lowers the same neighbour score by 9 points (63% to 54%), so the 5-point line was stricter than the source edit's own collateral; and the real target's rewordings lift (24 points) is four times that of the random-word edit (6 points; no significance test was run on this comparison), so what is tuned is not only a push on the exact sentence.

## 6. Mistakes and corrections
- The rerun bar was written into the plan by Claude as a proposal before the author had answered; it is marked "proposed" everywhere and was never used as a gate.
- Gate 5's neighbour line (5 points) turned out stricter than the source edit's own collateral (9 points inside small). The gate was not moved; the verdict stands as FAIL and the later gate (6) uses the source's own fall, with the reason written next to it.
- In D5 the random-vector control uses a different random seed from D3, so its numbers differ from D3's in noise; the translated, wrong-recipe and norm-matched numbers were checked against the older tool on 5 records and match exactly, and a zero dose reproduces the unchanged model.
- A review by another model (pasted by the author) warned of vanishing gradients through the SAE's non-linearity. That does not apply here: the SAE activations are computed once and held fixed, and the change is linear in the multipliers; D6 reached rank 1 at training time on 95%. The same review called the design novel; that claim is unchecked and the closest paper is in section 8.

## 7. What this does and does not show
Shows (within this model pair, CounterFact relations, 88 records, one injection layer in D6):
- Adding the same translated change at several layers does not improve the export; the layer is not the bottleneck.
- The channel itself (small's SAE features at layer 8, a linear map, medium layer 16) can carry an edit that makes the target medium's top answer on 95% of records, when the multipliers are tuned against medium's output. The original small-tuned edit reaches 8%. The mismatch is therefore between what moves small and what moves medium, not a closed channel.
- The tuned edit carries to rewordings (60%, against 42% for the same tuning toward a random word) at a neighbour cost (8 points) close to the source edit's own (9).
Does not show:
- A clean transfer: D6 uses medium's output for every sentence; it is a ceiling. Whether one trained map can do this without that is D7.
- That a fact moved: the channel carries a push toward any word too (random word, 83% top-1); the rewordings contrast is the only evidence of more than a push and has no significance test yet; Phase C of Entry 32 leaned toward read-out steering for the source edit itself.
- Anything about the additive edit, the Import direction, other model pairs, other relations, or generated text.

## 8. Related work (see `docs/cross_model_transfer/RELATED_WORK.md`)
Chen, Merullo, Stolfo and Pavlick (NeurIPS 2025), *Transferring Linear Features Across Language Models With Model Stitching* (arXiv 2506.06609), fit affine maps between residual streams of two models (including GPT-2 small and medium) and transfer SAEs, probes and steering vectors small to large; as summarised they report no experiment on fact edits. Our maps, stitching checks and country swap are in that family and are not claimed as new. Our different goal is carrying the change an edit makes, in both directions, with controls. The note was written from a summary of the paper, not from reading the full text; the claims must be checked before citation.
