## 1. The study in one paragraph
Send the change an edit makes inside GPT-2 small (layer 8, SAE `gpt2-small-res-jb`, 200 candidate features, one multiplier each: "the multiplier edit", never the additive edit) into GPT-2 medium (layer 16, no SAE) through a map fitted on ordinary text, at inference time, no weight change. **Export** = edit in small, add the translated change to medium. **Import** = medium's state into small. The baseline map is a linear (ridge) map of the residual stream `blocks.L.hook_resid_pre` fitted on wikitext; better translators were tried (a neural map, a linear map trained on edits with an output-matching loss, and per-sentence re-tuning of the dials through the map, D6). The SAE is used only where the edit is made. Motivation (from the main project: gradient-descent SAE multiplier editing in GPT-2 small, 271 of 300 held-out prompts to rank 1 against 161 for a fixed sweep; every edit needs an SAE for its own model; small often does not know the answer; rank 1 by steering alone is weak evidence): can an edit's effect be carried to another model, and can a stronger model teach a weaker one?

## 4. Explanations the user keeps asking for (keep consistent)
- **Three maps and one non-map:** the ridge map (fitted once on wikitext to copy states); the map trained on edits (same matrix, nudged so medium's answers move as small's do; `d7_map.pt`, `d10_map_*`, `d13_map_*`); a neural map (fits text better, exports no better); D6 (not a map: the 200 dials are re-tuned per sentence while watching medium's answer).
- **Why "ceiling":** D6 is the most the channel can carry when allowed to look at medium; it is not a transfer. It also gets 83% on a random word, so rank 1 alone is not evidence of a fact.
- **Why 289 not 800:** 1,450 candidate sentences, 829 dropped by the hold-out rule, 621 edited, the edit reached rank 1 on 47% = 289.
- **Import vs Export:** the translator copies states well (medium to small fits better) but small is a weak receiver in the swap control. Full replacement is a hybrid (medium's first 16 layers, a map, small's last 4) and breaks what small knew; a half-weight mix keeps most of it.
- **What the SAE did:** it is the interface for making the edit in small; the SAE-filtered Import carried almost nothing; S1: random directions with the same firing pattern reach 81% against 95%.
- **Fact or push:** Phase C, S2 and S3 agree: what carries is a push toward the targeted word (a random word gains about as much on rewordings).

## 6. Gotchas
- The command harness halves double backslashes in SHELL command text, and long heredocs with quotes can fail to parse: write scripts and docs with the Write/Edit tools, put patch scripts in files (scratchpad: `C:\Users\imalv\AppData\Local\Temp\claude\D--Projects-transient-steering\150e3cfc-7fd8-40d5-abf1-74290f7f88c1\scratchpad\`), and use single backslashes inside Edit calls. Do not chain `sleep` in Bash for long waits.
- `tokenizer(prompt)` / `tokenizer.encode` already include the start token in this setup; use `add_special_tokens=False` for single words.
- The median-rank convention: the upper middle value for an even count (the D8 file keeps the lower one).
- **GPU memory:** do not run two heavy jobs at once, and do not keep a big padded training set on the GPU: `pack()` pads every text to the longest (57 tokens), so 7,550 texts take 3.8 GB. When the card is nearly full (check `nvidia-smi`) the run slows 5 to 10 times without an error. Keep the data on the CPU and move batches, or store unpadded. Scale time estimates from the largest measured set, not the small ones.
- Heavy CPU rehearsals while a user job runs slow it a little; use 2 threads (`OMP_NUM_THREADS=2`).
- A tool run that the user declined must not be retried: wait for their instruction.
